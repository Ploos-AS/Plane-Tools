# M5.24 — ADS-B live frontend module rename

M5.24 removes the historical milestone-specific frontend filename `adsb-m52.js` and renames the live ADS-B controller to `adsb-live.js`.

## Scope

- `web/adsb-live.js` is the canonical live ADS-B frontend controller.
- `web/index.html` loads `/adsb-live.js` before the radar integration.
- `web/adsb-m52.js` is removed; no compatibility shim is retained.
- Existing M5.22 hook semantics are unchanged.
- Existing M5.23 ownership semantics are unchanged: `app.js` does not own live ADS-B refresh/render behavior.
- UI and regression tests now read the canonical live module name.

## Split decision

A further split was considered but deliberately deferred. The live module currently has one cohesive responsibility: snapshot retrieval, filtering, live-list rendering, refresh scheduling and the small radar hook boundary. Splitting that code now would add more script-order/global coupling without a clear independent runtime responsibility.

## Qualification

M5.24 is complete when `go test ./...`, `go vet ./...`, and `go build ./cmd/plane-tools` pass on the exact milestone HEAD.
