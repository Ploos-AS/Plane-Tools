# M2 — Local aircraft lookup foundation

Status: implemented

## Goal

Introduce a stable local aircraft lookup model and API before selecting or importing a large external aircraft dataset.

## Included

- `GET /api/v1/aircraft`
- Lookup by `icao24` or `registration`
- ICAO24 normalization to uppercase
- Registration normalization to uppercase
- ICAO24 validation as exactly six hexadecimal characters
- HTTP 404 for valid but unknown aircraft
- Local in-process seed dataset for deterministic tests and UI/API development
- Automated tests for normalization, lookup, invalid ICAO24, and not-found behavior

## Examples

```sh
curl 'http://localhost:8080/api/v1/aircraft?icao24=4787a2'
curl 'http://localhost:8080/api/v1/aircraft?registration=ln-ngm'
```

## Architecture note

The small built-in dataset is intentionally a development seed, not a production aircraft database. A later milestone should add an importable local dataset behind the same lookup contract so core functionality remains useful without API keys.

## Acceptance criteria

- [x] Lookup works by ICAO24.
- [x] Lookup works by registration.
- [x] Lookup inputs are normalized.
- [x] Invalid ICAO24 values return HTTP 400.
- [x] Unknown valid aircraft return HTTP 404.
- [x] No external provider or API key is required.
