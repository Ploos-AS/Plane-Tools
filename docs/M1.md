# M1 — Local aviation utilities

Status: implemented

## Goal

Deliver the first useful Plane Tools functionality without external providers,
datasets, SDR hardware, or API keys.

## Included

- Great-circle distance between two latitude/longitude positions.
- Initial true bearing between the positions.
- Aviation unit conversion:
  - nautical miles ↔ kilometres
  - knots ↔ kilometres per hour
  - feet ↔ metres
- JSON HTTP API under `/api/v1`.
- Browser UI backed by the same API.
- Go unit and handler tests.

## API

### Distance and bearing

`GET /api/v1/distance?lat1=58.2042&lon1=8.0854&lat2=59.9111&lon2=10.7528`

Response fields:

- `distance_nm`
- `bearing_deg`

### Unit conversion

`GET /api/v1/convert?value=100&from=kt&to=kph`

Supported units are `nm`, `km`, `kt`, `kph`, `ft`, and `m` in their
corresponding dimensional pairs.

## Acceptance criteria

- [x] Core calculations are local and deterministic.
- [x] Invalid coordinates return HTTP 400.
- [x] Unsupported unit pairs return HTTP 400.
- [x] Core calculations have automated tests.
- [x] Browser UI exposes both utilities.
- [x] No network provider is needed.
