# M5.5 — local aircraft trails

M5.5 adds short-lived aircraft trails to the local ADS-B radar view.

## Behaviour

- trail history exists only in browser memory
- no trail data is written to `/data`
- no external service receives trail data
- trails are keyed by ICAO24
- points older than two minutes are pruned
- each aircraft is capped at 24 trail points
- only receiver-relative positions (`distance_nm` + `bearing_deg`) are recorded
- trails follow the current radar range
- the selected aircraft trail is highlighted

## Controls

The radar panel includes:

- `Show 2-minute trails`
- `Clear trails`

Clearing trails immediately removes all accumulated browser-memory history.
Reloading the page also clears the history.

## Scope

M5.5 intentionally does not add persistent track recording, playback, databases,
server-side history, or external map/tracking integrations. Those would require a
separate storage and privacy design.
