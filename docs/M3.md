# M3 — Airport database foundation

Status: implemented

## Goal

Add local airport lookup with coordinates and runway information while preserving Plane Tools' local-first, no-API-key baseline.

## Data contract

Plane Tools reads OurAirports-compatible CSV files:

- `/data/airports.csv`
- `/data/runways.csv` (optional)

Paths can be overridden with:

- `PLANE_TOOLS_AIRPORTS_CSV`
- `PLANE_TOOLS_RUNWAYS_CSV`

If `airports.csv` is absent, Plane Tools falls back to a small built-in seed dataset. If an airport file exists but is malformed, startup fails explicitly. Missing `runways.csv` is allowed and simply produces airport records without runway details.

OurAirports publishes these datasets as UTF-8 CSV files and releases the data to the Public Domain. Plane Tools does not bundle or automatically download the upstream dataset.

## API

### Lookup by ICAO

`GET /api/v1/airport?icao=ENGM`

### Lookup by IATA

`GET /api/v1/airport?iata=OSL`

### Lookup by OurAirports ident

`GET /api/v1/airport?ident=ENGM`

Returned data can include:

- ident
- ICAO
- IATA
- airport name/type
- latitude/longitude
- elevation
- country/region
- municipality
- scheduled-service flag
- runway length/width/surface
- runway-end identifiers
- runway lighted/closed state

## OurAirports fields used

From `airports.csv`:

- `ident`
- `type`
- `name`
- `latitude_deg`
- `longitude_deg`
- `elevation_ft`
- `iso_country`
- `iso_region`
- `municipality`
- `scheduled_service`
- `gps_code`
- `icao_code`
- `iata_code`

From `runways.csv`:

- `airport_ident`
- `length_ft`
- `width_ft`
- `surface`
- `lighted`
- `closed`
- `le_ident`
- `he_ident`

- [x] Local airport lookup works without network access.
- [x] ICAO, IATA and ident lookups are indexed in memory.
- [x] OurAirports `airports.csv` is supported directly.
- [x] OurAirports `runways.csv` can enrich airport records.
- [x] Missing runway data does not prevent startup.
- [x] Missing airport data falls back to seed records.
- [x] Malformed airport data fails explicitly.
- [x] Automated tests cover loading, runway enrichment and API lookup.
