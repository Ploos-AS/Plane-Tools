# M5.2 — Live ADS-B filtering and receiver-relative geometry

M5.2 makes the live receiver view useful for active spotting by calculating aircraft distance/bearing and by adding server-side filtering and sorting.

## Receiver position

Set the physical receiver/antenna position with both variables:

```text
PLANE_TOOLS_ADSB_LAT=58.2042
PLANE_TOOLS_ADSB_LON=8.0854
```

Both values must be supplied together and must be valid latitude/longitude values. Plane Tools fails startup on invalid configuration.

When the receiver position and aircraft position are both available, live aircraft records include:

- `distance_nm`
- `bearing_deg`

`GET /api/v1/adsb/status` also reports whether receiver position is configured.

## Filtered live-aircraft API

```text
GET /api/v1/adsb/aircraft/search
```

Supported query parameters:

- `q` — matches ICAO24, callsign, registration or type code
- `min_altitude_ft`
- `max_altitude_ft`
- `max_distance_nm`
- `sort=distance|altitude|registration|callsign|seen`
- `order=asc|desc`

Default sorting is nearest aircraft first. Aircraft without a calculated distance are placed after aircraft with distance when sorting by distance. A `max_distance_nm` filter excludes aircraft that do not have enough position data to calculate distance.

## Web UI

The live ADS-B panel now exposes the same filters and sorting. Distance and bearing are shown inline when receiver geometry is configured. Auto-refresh continues to use the active filter settings.

All filtering is performed by Plane Tools against the configured local receiver feed. No external tracking provider is contacted.
