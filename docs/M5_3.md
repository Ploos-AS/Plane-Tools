# M5.3 — local ADS-B radar view

M5.3 adds a fully local receiver-centred radar view to the embedded Plane Tools web UI.

## Scope

- HTML canvas radar plot embedded in the existing UI
- receiver fixed at plot centre
- 45-degree bearing spokes
- four range rings
- selectable 25, 50, 100 or 200 NM display range
- live aircraft plotted from `distance_nm` and `bearing_deg`
- aircraft marker rotates to `track_deg` when available
- label uses registration, callsign or ICAO24
- altitude shown when available
- radar refreshes with the existing live ADS-B refresh cycle and active M5.2 filters

The radar uses only the receiver-relative geometry already produced by Plane Tools.
Aircraft without usable position/distance are omitted from the plot but remain available in the live aircraft list.

## Privacy and dependencies

The view does not use map tiles, geocoding, analytics, CDN assets or third-party tracking services.
No browser request is made outside Plane Tools itself.

## Configuration

Receiver-relative geometry requires:

```text
PLANE_TOOLS_ADSB_LAT=<receiver latitude>
PLANE_TOOLS_ADSB_LON=<receiver longitude>
```

The existing receiver configuration is unchanged:

```text
PLANE_TOOLS_ADSB_URL=http://readsb:8080
PLANE_TOOLS_ADSB_TIMEOUT=3s
```
