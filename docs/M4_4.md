# M4.4 — Logbook web UI

M4.4 exposes the local spotting workflow in the embedded Plane Tools browser UI.

The page now includes:

- aircraft lookup by ICAO24 or registration
- a spotting-log entry form
- recent sightings loaded from the local logbook API
- logbook summary cards for sightings, unique aircraft, first seen and last seen
- lifelist rendering
- JSON and CSV export links

The UI uses the existing local `/api/v1/*` endpoints. It does not add third-party JavaScript, external fonts, map providers, analytics, cloud storage, or API-key requirements.

Observation creation accepts an RFC3339 timestamp or uses the current browser time converted to UTC. ICAO24 and registration values are normalized by the server. Airport and spotting-location fields remain optional and are validated by the existing backend.

Acceptance criteria:

- [x] embedded UI can look up aircraft
- [x] embedded UI can create spotting observations
- [x] recent observations are visible without external services
- [x] logbook summary and lifelist are visible
- [x] JSON and CSV exports are reachable from the UI
- [x] existing distance and conversion tools remain available
