# M5.4 — Interactive ADS-B radar

M5.4 makes the local ADS-B radar interactive without introducing any new external service or backend dependency.

## Behaviour

- Click an aircraft marker on the radar to select it.
- Click a live-aircraft list row to select the same aircraft.
- The selected aircraft is highlighted in both the radar and live list.
- A local detail panel shows the selected aircraft identity and available telemetry.
- The detail panel has an **Add sighting** action that pre-fills the existing spotting-log form.
- Selection follows the current filtered live dataset and is cleared if the aircraft disappears from that dataset.
- Radar range changes preserve selection when the selected aircraft remains available.

## Data flow

M5.4 uses the existing M5.2/M5.3 normalized live-aircraft payload. No extra provider calls are made.

The radar uses receiver-relative `distance_nm` and `bearing_deg`, while `track_deg` controls aircraft marker orientation when available.

## Privacy and locality

- no map tiles
- no CDN
- no geocoding service
- no external aircraft-tracking provider
- no new API keys
- no automatic spotting-log writes

The **Add sighting** action only pre-fills the local form. The user still chooses airport/location and explicitly submits the observation.
