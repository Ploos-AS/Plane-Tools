# M2.1 — Importable aircraft dataset

Status: implemented

## Goal

Replace the fixed in-process sample lookup path with a local dataset contract
that can be populated independently of Plane Tools and queried efficiently.

## Dataset path

By default Plane Tools looks for:

`/data/aircraft.csv`

The path can be overridden with `PLANE_TOOLS_AIRCRAFT_CSV`.

If the file does not exist, Plane Tools falls back to the small built-in seed
dataset from M2. A present but malformed dataset is treated as a startup error
rather than silently ignored.

## CSV schema

Required columns:

- `icao24`
- `registration`
- `type_code`
- `manufacturer`
- `model`

Optional columns:

- `operator`

Example:

```csv
icao24,registration,type_code,manufacturer,model,operator
4787A2,LN-NGM,B738,Boeing,737-800,Norwegian
```

ICAO24 values are normalized to uppercase and must contain exactly six
hexadecimal characters. Registrations and type codes are normalized to
uppercase.

## Lookup model

The dataset is parsed once at startup and indexed in memory by both ICAO24 and
registration, preserving the existing `GET /api/v1/aircraft` API contract.

## Acceptance criteria

- [x] CSV dataset can be loaded from `/data`.
- [x] Dataset path is configurable.
- [x] Missing dataset falls back to built-in seed data.
- [x] Malformed schema or records fail explicitly.
- [x] Lookup is indexed by ICAO24 and registration.
- [x] Existing lookup API remains compatible.
- [x] Import and fallback paths have automated tests.
