# M4.5 — Airport and spotting-location UI

M4.5 exposes the existing local airport and spotting-location APIs in the embedded Plane Tools web UI.

## Airport UI

The browser can now:

- search airports by ICAO, IATA, name, municipality, country or region
- find nearby airports from latitude/longitude with radius and result limit
- copy a selected airport ident directly into the spotting-location form and sighting form

All queries use the local airport dataset already loaded by Plane Tools. No external airport API is contacted.

## Spotting-location UI

The browser can now:

- list saved spotting locations
- create a location with name and coordinates
- optionally bind a location to an airport ident
- edit an existing location while preserving its ID
- delete an existing location
- refresh the saved-location list

The sighting form now uses a select control populated from saved spotting locations instead of requiring users to type a location ID manually. Selecting a location with an explicit airport binding also fills the airport ident in the sighting form.

## Qualification

A static web smoke test verifies that the embedded HTML contains the expected UI controls and that the JavaScript contains hooks for the airport search, nearby-airport and spotting-location APIs.

## Privacy

The UI remains dependency-free and local-first. It adds no third-party JavaScript, analytics, fonts, map provider or cloud service.
