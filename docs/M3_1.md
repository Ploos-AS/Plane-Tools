# M3.1 — Airport search and nearby

M3.1 extends the local airport database with two discovery APIs useful for plane spotting.

## Search

`GET /api/v1/airports/search?q=<text>&limit=<n>`

Search is case-insensitive and matches airport ident, ICAO, IATA, name, municipality, country and region. Results are sorted by name and then ident. The default limit is 20 and the maximum is 100.

Example:

```sh
curl 'http://localhost:8080/api/v1/airports/search?q=kristiansand'
```

## Nearby

`GET /api/v1/airports/nearby?lat=<lat>&lon=<lon>&radius_nm=<nm>&limit=<n>`

The endpoint calculates great-circle distance locally using the same Haversine implementation as the distance utility. Results are sorted nearest first and each entry includes `distance_nm` plus the airport record.

Defaults:

- `radius_nm`: 50 NM
- `limit`: 20

Limits:

- `radius_nm`: greater than 0 and at most 1000 NM
- `limit`: 1–100

Example:

```sh
curl 'http://localhost:8080/api/v1/airports/nearby?lat=58.2042&lon=8.0854&radius_nm=100'
```

## Privacy and network behaviour

Search and nearby calculations are entirely local. No coordinates or search terms are sent to an external service.
