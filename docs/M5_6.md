# M5.6 — Radar usability

M5.6 improves the local ADS-B radar workflow without adding external services or persistent tracking history.

## Freeze live view

`Freeze live view` keeps the current live list and radar frame on screen while the receiver continues operating independently. Unfreezing triggers an immediate refresh.

## Follow selected aircraft

When enabled, selecting an aircraft keeps that selection through short receiver/feed gaps for up to 30 seconds. The last known detail remains visible and is marked as temporarily absent. If the aircraft reappears, live detail and highlighting resume automatically.

If a selected aircraft is outside the current radar range, Plane Tools automatically expands to the smallest configured radar range that contains it (25, 50, 100 or 200 NM).

## Configurable trails

Radar trails remain browser-memory only. The user can choose:

- 30 seconds
- 1 minute
- 2 minutes
- 5 minutes

History is still bounded to a maximum number of points per ICAO24 and is pruned automatically. Reloading the page or using `Clear trails` removes the in-memory history.

## Privacy boundary

M5.6 does not add:

- server-side flight history
- `/data` persistence for live positions
- cloud services
- external tracking providers
- map tile or geocoding dependencies

The live receiver remains read-only from Plane Tools' perspective.
